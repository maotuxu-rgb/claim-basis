# 承揽合同 · 建设工程合同 — 请求权基础目录

> 本文件是 SKILL.md 的配套参考（见 3.5 节）。分析框架与四步审查结构见 SKILL.md 一、分析框架。

## 一、承揽合同（第770—787条）

| 条文 | 简要内容 | 请求权类型 |
|------|----------|------------|
| 第772条 | 承揽人将主要工作擅自转包或分包的，定作人可解除合同并请求损害赔偿 | 解除 / 损害赔偿 |
| 第773条 | 承揽人分包的，就分包人完成的工作对定作人承担责任 | 违约担责 |
| 第774条 | 承揽人须按约提供材料并接受定作人检验；不符合要求须更换 | 材料替换请求权 |
| 第775条 | 定作人提供的材料不符合要求，经承揽人告知后造成的损失由定作人负担 | 损害赔偿 |
| 第776条 | 定作人的图纸或技术要求不合理，承揽人及时告知；定作人拒不改变造成损失的，由定作人负担 | 损害赔偿 |
| 第777条 | 定作人中途变更要求致承揽人损失的，应赔偿 | 损害赔偿 |
| 第778条 | 定作人未履行协助义务，经催告仍不履行，承揽人可解除合同并请求赔偿 | 解除 / 损害赔偿 |
| 第779条 | 定作人可随时检验工作进度和质量，但不得妨碍承揽人正常工作 | 检验权 |
| 第780条 | 承揽人完成工作后须交付成果及相关技术资料；定作人须验收 | 交付 / 验收请求权 |
| 第782条 | 定作人须按约支付报酬；承揽人分批交付的，分批支付 | 报酬请求权 |
| 第784条 | 承揽人因保管不善致定作人材料或工作成果毁损灭失，应赔偿 | 损害赔偿 |
| 第785条 | 承揽人须保守定作人商业秘密，不得留存图纸等资料；违反时赔偿损失 | 保密义务（违反→损害赔偿）|
| 第786条 | 多个承揽人共同完成工作的，对定作人承担连带责任 | 连带责任 |
| 第787条 | 定作人在工作完成前可随时解除合同，但须赔偿承揽人已发生的损失 | 损害赔偿 |

> **竞合提示**：承揽合同与买卖合同的区分——以劳务为主、附带提供材料的为承揽；以转移财产所有权为主的为买卖。材料由定作人提供时，品质问题适用第775条（承揽）而非第615条（买卖瑕疵担保）。

## 二、建设工程合同（第788—807条）

| 条文 | 简要内容 | 请求权类型 |
|------|----------|------------|
| 第791条 | 总承包人将主体工程转包或未经发包人同意分包的，承担相应违约责任 | 违约损害赔偿 |
| 第793条 | 建设工程施工合同无效，但工程验收合格的，可参照合同约定请求支付工程价款 | 折价补偿 / 价款请求权 |
| 第797条 | 发包人可随时检查工程进度与质量，但不得妨碍承包人正常工作 | 检验权 |
| 第799条 | 工程竣工后发包人须依法验收；验收合格后方能交付使用，验收合格触发付款义务 | 验收 / 付款请求权 |
| 第801条 | 工程质量不符合约定，发包人可请求承包人免费修复或赔偿损失；承包人延误工期须承担违约责任 | 修复 / 损害赔偿 |
| 第802条 | 承包人须在合理使用期限内对工程质量承担保修责任 | 质量保修请求权 |
| 第804条 | 因发包人原因导致工程停建或缓建，发包人须赔偿承包人损失 | 损害赔偿 |
| 第805条 | 因发包人变更设计或增加工程量，承包人可请求补偿相应费用 | 费用补偿请求权 |
| 第806条 | 承包人发现重大地质条件等变化须及时通知；因发包人原因导致的损失由发包人承担 | 损害赔偿 |
| 第807条 | 发包人未按约付款，承包人对已完工程享有优先受偿权（优先于抵押权及一般债权）| 建设工程价款优先受偿权 |

> **第793条适用要点**：合同虽无效，验收合格时承包人可请求价款（折价补偿），此时第157条通则与第793条特别规定的关系——第793条优先；合同无效且工程不合格的，承包人不享有此保护，须承担修复义务或赔偿损失。
>
> **第807条优先受偿权**：属于法定优先权，须在建设工程竣工之日或合同约定竣工之日起18个月内行使（参照《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》第41条）。
