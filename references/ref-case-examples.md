## 5.1 合同失败返还——案例三（汽车起重机买卖）

**事实核心**：出卖人甲以欺诈手段出卖套牌车，买受人乙支付价款后车辆被公安机关销毁。

### 场景 A：乙行使撤销权（合同被撤销）

**首选请求权基础**：第157条（合同被撤销后折价补偿）

| 审查步骤 | 涉及条文与规范类型 | 结论 |
|----------|-------------------|------|
| 产生要件 | 第157条 `〈主要〉` + 第148条 `〈辅助〉`（撤销权行使前提）| ① 双务买卖合同 ✓ ② 乙依第148条行使撤销权后合同溯及无效 ✓ ③ 乙的价款给付已由甲取得 ✓ ④ 车辆被销毁无法原物返还 ✓ |
| 权利发生抗辩 | 第526条 `〈抗辩〉`（经第157条提示参引准用）| 甲可对乙主张同时履行抗辩权（乙须同时返还使用利益） |
| 权利消灭抗辩 | 第152条第1款第1项 `〈抗辩〉` | 注意撤销权除斥期间（欺诈1年）|
| 权利行使抗辩 | — | 甲的折价补偿反请求权是否成立 → 乙用益返还义务的范围 |

**竞合分析**：
- 第985条不当得利：第157条为特别规范，优先适用；第985条仅在合同成立前或第157条不能涵盖时补充
- 第500条缔约过失（欺诈）：可独立主张信赖利益赔偿，但不得与第157条折价补偿重复计算

### 场景 B：乙未撤销合同（合同有效）

**首选请求权基础**：第577条违约损害赔偿（甲交付套牌车构成权利瑕疵违约）

| 路径 | 条文 | 规范类型 | 要件要点 |
|------|------|----------|----------|
| 违约赔偿 | 第577条 + 第612条 | `〈主要〉` + `〈主要〉` | 甲违反第612条权利瑕疵担保 → 第577条赔偿乙损失 |
| 品质瑕疵参引 | 第615条 → 第617条 → 第582—584条 | `〈主要〉` → `〈提示参引〉` → `〈主要〉``〈辅助〉``〈抗辩〉` | 第617条提示参引第582—584条，直接适用瑕疵救济 |
| 解除+返还 | 第563条第1款第4项 + 第566条 | `〈抗辩〉` + `〈主要〉` | 权利瑕疵致合同目的不能实现 → 解除 → 恢复原状 |

## 5.2 违约方申请解除——案例四（商铺买卖）

**事实核心**：出卖人甲公司（违约方）因商场改造需要，向法院申请解除与买受人乙的商铺买卖合同，并请求乙返还商铺。

**首选请求权基础**：第566条第1款第2分句（合同解除后恢复原状）

### 核心问题：甲公司（违约方）能否解除合同？

| 解除路径 | 规范类型 | 结论 | 理由 |
|----------|----------|------|------|
| 第563条法定解除权 | `〈抗辩〉` | **不成立** | 甲为违约方，不享有法定解除权；乙未构成第1款第4项之违约（办理过户仅为乙的不真正义务）|
| **第580条第2款司法解除** | `〈辅助/抗辩〉` | **可能成立** | 违约方亦可申请；要件：①有效非金钱债务 ②无法继续履行 ③导致合同目的不能实现 ④向法院申请 |
| 第533条情势变更 | `〈主要〉` | 补充审查 | 具有补充性，在前两条均不适用时方予审查 |

**第580条第2款要件检视**（本案）：

| 要件 | 分析 |
|------|------|
| 有效非金钱债务 | 甲公司负有交付商铺并过户的债务 ✓ |
| 债务无法继续履行 | 甲公司已施工拆改，是否构成事实上不能履行 → 需进一步认定 |
| 合同目的不能实现 | 乙的合同目的（取得可经营商铺）是否因此不能实现 → 核心争议点 |
| 申请要件 | 甲公司已向法院提起诉讼 ✓ |

> **重要规则**：第580条第2款不以《九民纪要》第48条所列三项要件（非恶意违约、显失公平、守约方违反诚信）为前提；《民法典》施行后，法院应直接适用第580条第2款，不得以会议纪要要件替代法定要件。

**不当得利竞合（备选）**：
- 合同有效且未解除时：乙基于有效合同取得占有，给付有法律上原因，第985条**不成立**
- 若第580条第2款履行不能成立：甲因永久抗辩权无法继续履行，给付目的嗣后落空（给付无法律上原因），第985条**可独立支持返还请求**，构成第566条第1款的替代请求权基础

## 5.3 参引规范在四步审查中的处理示例

### 提示参引：直接适用（以案例三B为例）

第617条规定出卖人品质瑕疵时买受人"可以依据本法第582条至第584条的规定请求承担违约责任"。

**处理步骤**：
1. 识别第617条为 `〈提示参引〉`，被参引规范为第582—584条
2. 直接适用被参引规范：第582条 `〈主要/抗辩〉`（瑕疵救济）、第583条 `〈主要〉`（补正后赔偿）、第584条 `〈辅助〉`（可预见规则）+ `〈抗辩〉`（可预见上限）
3. 无需论证类推适用的正当性——提示参引仅起提示功能
4. 分析报告记载："依第617条提示参引，适用第582条瑕疵履行救济"

### 类推参引：须论证正当性（假设案例）

若案例涉及无名合同纠纷，第467条第1款规定"参照适用最相类似类型的合同"。

**处理步骤**：
1. 识别第467条第1款为 `〈类推参引〉`
2. 确定最相类似的有名合同类型（如承揽合同）
3. **论证类推正当性**：该无名合同与承揽合同在给付内容、风险分配、当事人地位等方面具有实质相似性
4. 排除"性质不能适用"的情形：检查被参引规范是否与本合同性质冲突
5. 分析报告记载类推论证过程，而非仅引用条文号
