## 5.1 合同失败返还——案例三（汽车起重机买卖）

**事实核心**：出卖人甲以欺诈手段出卖套牌车，买受人乙支付价款后车辆被公安机关销毁。

### 场景 A：乙行使撤销权（合同被撤销）

**首选请求权基础**：第157条（合同被撤销后折价补偿）

| 审查步骤 | 涉及条文与规范类型 | 结论 |
|----------|-------------------|------|
| 产生要件 | 第157条 `〈主要〉` + 第148条 `〈辅助〉`（撤销权行使前提）| ① 双务买卖合同 ✓ ② 乙依第148条行使撤销权后合同溯及无效 ✓ ③ 乙的价款给付已由甲取得 ✓ ④ 车辆被销毁无法原物返还 ✓ |
| 权利发生抗辩 | 第526条 `〈抗辩〉`（经第157条提示参引准用）| 甲可对乙主张同时履行抗辩权（乙须同时返还使用利益） |
| 权利消灭抗辩 | 第152条第1款第1项 `〈抗辩〉` | 注意撤销权除斥期间（欺诈1年）|
| 权利行使抗辩 | — | 甲的折价补偿反请求权是否成立 → 乙用益返还义务的范围 |

**竞合分析**：
- 第985条不当得利：第157条为特别规范，优先适用；第985条仅在合同成立前或第157条不能涵盖时补充
- 第500条缔约过失（欺诈）：可独立主张信赖利益赔偿，但不得与第157条折价补偿重复计算

### 场景 B：乙未撤销合同（合同有效）

**首选请求权基础**：第577条违约损害赔偿（甲交付套牌车构成权利瑕疵违约）

| 路径 | 条文 | 规范类型 | 要件要点 |
|------|------|----------|----------|
| 违约赔偿 | 第577条 + 第612条 | `〈主要〉` + `〈主要〉` | 甲违反第612条权利瑕疵担保 → 第577条赔偿乙损失 |
| 品质瑕疵参引 | 第615条 → 第617条 → 第582—584条 | `〈主要〉` → `〈提示参引〉` → `〈主要〉``〈辅助〉``〈抗辩〉` | 第617条提示参引第582—584条，直接适用瑕疵救济 |
| 解除+返还 | 第563条第1款第4项 + 第566条 | `〈抗辩〉` + `〈主要〉` | 权利瑕疵致合同目的不能实现 → 解除 → 恢复原状 |

## 5.2 违约方申请解除——案例四（商铺买卖）

**事实核心**：出卖人甲公司（违约方）因商场改造需要，向法院申请解除与买受人乙的商铺买卖合同，并请求乙返还商铺。

**首选请求权基础**：第566条第1款第2分句（合同解除后恢复原状）

### 核心问题：甲公司（违约方）能否解除合同？

| 解除路径 | 规范类型 | 结论 | 理由 |
|----------|----------|------|------|
| 第563条法定解除权 | `〈抗辩〉` | **不成立** | 甲为违约方，不享有法定解除权；乙未构成第1款第4项之违约（办理过户仅为乙的不真正义务）|
| **第580条第2款司法解除** | `〈辅助/抗辩〉` | **可能成立** | 违约方亦可申请；要件：①有效非金钱债务 ②无法继续履行 ③导致合同目的不能实现 ④向法院申请 |
| 第533条情势变更 | `〈主要〉` | 补充审查 | 具有补充性，在前两条均不适用时方予审查 |

**第580条第2款要件检视**（本案）：

| 要件 | 分析 |
|------|------|
| 有效非金钱债务 | 甲公司负有交付商铺并过户的债务 ✓ |
| 债务无法继续履行 | 甲公司已施工拆改，是否构成事实上不能履行 → 需进一步认定 |
| 合同目的不能实现 | 乙的合同目的（取得可经营商铺）是否因此不能实现 → 核心争议点 |
| 申请要件 | 甲公司已向法院提起诉讼 ✓ |

> **重要规则**：第580条第2款不以《九民纪要》第48条所列三项要件（非恶意违约、显失公平、守约方违反诚信）为前提；《民法典》施行后，法院应直接适用第580条第2款，不得以会议纪要要件替代法定要件。

**不当得利竞合（备选）**：
- 合同有效且未解除时：乙基于有效合同取得占有，给付有法律上原因，第985条**不成立**
- 若第580条第2款履行不能成立：甲因永久抗辩权无法继续履行，给付目的嗣后落空（给付无法律上原因），第985条**可独立支持返还请求**，构成第566条第1款的替代请求权基础

## 5.3 参引规范在四步审查中的处理示例

### 提示参引：直接适用（以案例三B为例）

第617条规定出卖人品质瑕疵时买受人"可以依据本法第582条至第584条的规定请求承担违约责任"。

**处理步骤**：
1. 识别第617条为 `〈提示参引〉`，被参引规范为第582—584条
2. 直接适用被参引规范：第582条 `〈主要/抗辩〉`（瑕疵救济）、第583条 `〈主要〉`（补正后赔偿）、第584条 `〈辅助〉`（可预见规则）+ `〈抗辩〉`（可预见上限）
3. 无需论证类推适用的正当性——提示参引仅起提示功能
4. 分析报告记载："依第617条提示参引，适用第582条瑕疵履行救济"

### 类推参引：须论证正当性（假设案例）

若案例涉及无名合同纠纷，第467条第1款规定"参照适用最相类似类型的合同"。

**处理步骤**：
1. 识别第467条第1款为 `〈类推参引〉`
2. 确定最相类似的有名合同类型（如承揽合同）
3. **论证类推正当性**：该无名合同与承揽合同在给付内容、风险分配、当事人地位等方面具有实质相似性
4. 排除"性质不能适用"的情形：检查被参引规范是否与本合同性质冲突
5. 分析报告记载类推论证过程，而非仅引用条文号

## 5.4 侵权·特殊侵权与违约竞合——喂猴被伤案

**事实核心**：4岁儿童钻越动物园护栏喂猴被咬伤，请求动物园赔偿（含财产、假肢、精神损害）。

**首选请求权基础**：第1248条主文（动物园动物致害，过错推定）——优先于第1165条一般侵权与第1198条安全保障义务；并与第577条违约（违反保护义务）竞合。

> **完整检视流程**（特殊侵权预选 → 责任成立清单 → 责任范围清单 → 与有过失含监护人过失 → 竞合）见 `ref-tort-liability.md` 的"〔适用逻辑〕侵权请求权完整检视流程"。要点：①特殊侵权优先识别；②第1248过错推定由动物园举证免责；③无行为能力受害人的**法定代理人监护过失**计入与有过失扣减；④财产损害按差额说、精神损害须达"严重"。

## 5.5 物权·不动产善意取得——房屋善意取得案

**事实核心**：担保公司凭甲签署并公证的授权委托书、持权属证书原件，代理（无真实授权）将甲房屋卖与乙、再转卖丙并完成登记；丙诉请甲腾退交付房屋。

**首选请求权基础**：第235条（所有物返还）——核心在于"丙是否为所有人"，须沿 甲→乙→丙 逐环审查所有权变动，其中含**表见代理**与**不动产善意取得**判断。

> **完整检视流程**（历史方法定所有权归属 → 自权利人/无权利人取得分流 → 善意取得清单 → 占有本权举证倒置 → 所有人占有人关系定位）见 `ref-property-rights.md` 的"〔适用逻辑〕所有物返还与不动产善意取得检视流程"。要点：①第235条真正要件仅2项，占有本权为相对人举证之抗辩；②善意取得权利外观=登记名义、恶意（重大过失）由原权利人举证、基准时为完成登记时；③"未查看占有是否构成重大过失"为个案开放争点。

## 5.6 侵权·一般侵权与公平责任边界——电梯劝烟案

**事实核心**：乙在电梯内平和劝阻甲（69岁、有心脏病史）吸烟，争执后甲于数分钟后心脏病突发死亡，甲配偶丙索赔。

**首选请求权基础**：第1181条第1款第1句（死者近亲属侵权损害赔偿，固有说→独立请求权基础）——其成立以"乙对甲的一般侵权（第1165条）成立"为前提。

> **完整检视流程**（近亲属请求权定位 → 一般侵权责任成立·条件性+相当性〔特殊体质〕+不法性+过错 → 公平责任第1186条的正确定位）见 `ref-tort-liability.md` 的"〔适用逻辑〕一般侵权的责任成立与公平责任的边界"。要点：①正当平和的劝阻不具不法性、相当因果关系难成立→侵权不成立；②**第1186公平责任是提示参引、非独立请求权基础**，须"第1186+具体规定"（体系内仅第182②、1188②、1190①后段三处），不得仅因损害严重即分担。

## 5.7 合同无效返还·房地一体与添附——画家村案

**事实核心**：城镇居民乙购买甲的农村宅基地上房屋并装修、新建厢房，多年后甲诉请确认合同无效、返还房屋；乙反诉赔偿。

**首选请求权基础**：合同因违反宅基地流转的效力性强制规定而无效 → 第157条返还+折价补偿、第235条原物返还、第985条给付不当得利、第322条添附物归属与补偿。

> **完整检视流程**（合同效力判断〔效力性强制规定/公序良俗/房地一体〕 → 无效后返还请求权群〔区别于第566解除〕 → 添附与信赖利益 → 确认无效不适用时效）见 `ref-contract-claims.md` §1.6 的"〔适用逻辑〕合同无效的认定与无效后返还的请求权群"。要点：①合同无效不走第566（解除以有效合同为前提）；②返还走第157/235/985+用益返还，添附依第322处理归属与补偿；③确认无效之诉不适用诉讼时效。

## 5.8 担保·抵押合同有效但未登记的违约赔偿责任——中信银行东莞分行案（指导案例168号）

**事实核心**：银行与抵押人签订《最高额抵押合同》（含"声明与保证"及"违约责任"条款），约定以抵押人的房产担保银行对借款人的债权；但因抵押房屋与所占土地权属不一致、抵押人未取得土地使用权证，**抵押始终未办理登记，抵押权未设立**。主债务人违约后，银行**不主张优先受偿，而是请求抵押人在抵押物价值范围内承担"赔偿责任"**。当地房产管理局曾于放款前两年发函各金融机构，明确此类房屋无法办理抵押登记、应审慎放款。

**首选请求权基础**：**违约损害赔偿（第577条 + 第584条）**，而非担保物权优先受偿——核心在于抵押合同的**"声明与保证 + 违约责任"条款**将"可登记性"转化为抵押人的合同义务。

> **关键甄别**：银行诉请措辞是"**赔偿**责任"而非"**优先受偿**"，这一信号应顺势导向**违约赔偿**路径，**切勿误入"担保责任成立与否"的归责开关**（如以"未登记非因抵押人原因"径直免责）。

| 审查步骤 | 涉及条文与规范类型 | 结论 |
|----------|-------------------|------|
| ① 抵押合同效力 | 第215条 `〈辅助〉`（区分原则）| 物权变动登记与否**不影响合同效力**；《最高额抵押合同》系真实意思、不违反强制规定 → **有效** |
| ② 抵押权是否设立 | 第402条 `〈辅助〉`（不动产抵押登记生效）| 未办理登记 → **抵押权未设立，无优先受偿权**（银行据此只能转求违约赔偿）|
| ③ 违约是否成立 | 第577条 `〈主要〉` + 合同"声明与保证/违约责任"条款 | 抵押人**承诺保证抵押物权属完整、可依法办理登记**；因房地权属不一致、缺土地使用权证致登记不能 → **声明不实/义务未履行 → 违约成立** |
| ④ 损失范围 | 第584条 `〈辅助〉`（可预见规则）| 损失 = 抵押权正常设立时本可优先受偿之数额 = **抵押物价值范围内、主债务未受清偿部分** |
| ⑤ 减责事由 | 第591条第1款 `〈抗辩〉`（减损义务）+ 过失相抵 | 银行为专业金融机构、明知房管局函仍放款且未尽更高审查义务，事后未采取降额/补充担保等减损措施 → **按双方过错酌减** |

**核心规则（裁判要点）**：
1. 以不动产抵押，抵押人未依约办理登记的，**不影响抵押合同效力**（区分原则）；
2. 债权人依抵押合同主张抵押人**在抵押物价值范围内承担违约赔偿责任**的，应予支持；
3. **抵押权人对未能办理登记有过错的，相应减轻抵押人的赔偿责任**（本案酌定为未清偿债务的**二分之一**）。

> **方法论戒律**——本案最易踩的两个坑：
> - **路径选择**：抵押合同含声明与保证条款时，抵押人责任源于**违约（第577条）**，损害以抵押物价值为限；不要套用担保物权或"担保责任归责"框架。
> - **债权人过错的功能定位**：债权人过错落在**过失相抵 / 减损义务（第591条）→ 按比例减责**，而非阻却责任成立的"全有全无"开关。除非完全可归责于债权人，否则不应据此让抵押人全部免责。
>
> **新旧法映射**：物权法第15条 → 第215条；合同法第107、113①、119① → 第577、584、591①。指导案例168号（2021-11-09发布）确立的范式现行有效。
