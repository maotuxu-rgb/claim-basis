# 保管合同 · 仓储合同 — 请求权基础目录

> 本文件是 SKILL.md 的配套参考（见 3.5 节）。分析框架与四步审查结构见 SKILL.md 一、分析框架。

---

## 一、保管合同（第888—901条）

| 条文 | 简要内容 | 请求权类型 |
|------|----------|------------|
| 第889条 | 寄存人交付保管物后，保管人须出具保管凭证 | 凭证请求权 |
| 第891条 | 保管人须按约或依保管物性质妥善保管；保管条件变更须通知寄存人 | 妥善保管义务（违反→损害赔偿）|
| 第892条 | 保管人须妥善保管保管物；因保管不善致毁损灭失的，承担赔偿责任（有偿保管无过错抗辩受限）| 损害赔偿 |
| 第893条 | 寄存人未告知危险物品性质，保管人因此受损的，保管人可请求赔偿 | 损害赔偿（保管人→寄存人）|
| 第894条 | 保管人未经同意将保管物转交第三人保管致损失的，应赔偿 | 损害赔偿 |
| 第895条 | 保管人不得使用保管物；未经同意使用的，须赔偿损失并支付使用费 | 损害赔偿 / 使用费请求权 |
| 第896条 | 第三人对保管物主张权利时，保管人应继续履行向寄存人返还的义务，不得向第三人擅自处置 | 返还请求权 |
| 第897条 | 保管人因保管不善致保管物毁损灭失，应赔偿；无偿保管人仅在故意或重大过失时赔偿 | 损害赔偿 |
| 第899条 | 寄存人可随时领取保管物（无论期限是否届满）| 随时取回权 |
| 第900条 | 保管期满或寄存人领取时，保管人须返还原物及其孳息 | 返还请求权（含孳息）|

## 二、仓储合同（第902—917条）

| 条文 | 简要内容 | 请求权类型 |
|------|----------|------------|
| 第902条 | 存货人须按约定期限支付保管费；逾期不支付的，保管人可催告并有留置权 | 保管费请求权 |
| 第906条 | 存货人委托保管危险物品须如实告知性质，保管人须具备相应保管条件；产生的额外费用由存货人负担 | 费用请求权 |
| 第907条 | 保管人须在入库时验收仓储物，验收后发现的毁损灭失由保管人承担赔偿责任 | 损害赔偿 |
| 第908条 | 保管人须向存货人出具仓单等凭证 | 凭证请求权 |
| 第909条 | 保管人须在仓单上签名或盖章，仓单须载明法定事项 | 仓单签发义务（违反→损害赔偿）|
| 第911条 | 存货人或仓单持有人有权检查仓储物或提取样品，保管人须配合 | 检查 / 取样权 |
| 第915条 | 存货人或仓单持有人提货时，须凭仓单或其他凭证；逾期提货须支付额外仓储费 | 提货权 / 仓储费请求权 |
| 第917条 | 保管人因保管不善致仓储物毁损灭失，应赔偿 | 损害赔偿 |

> **保管合同与仓储合同的主要区别**：
> - 保管合同（第888条）：以保管为目的，保管人不必经营仓库
> - 仓储合同（第904条）：存货人须为经营活动、须有仓库设施；仓单可流通转让（背书转让）
>
> **仓单的流通性**：仓单记载的货物可依仓单转让（第912条），持有仓单者即享有提货权，保管人须向持单者履行；第907条验收义务是分配风险的关键节点。
