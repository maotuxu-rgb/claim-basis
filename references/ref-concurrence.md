# 请求权竞合处理（权威）

> 本文件是技能内竞合处理的**单一权威**。SKILL.md §四 及各 reference 的"竞合"小节均指向此处。
> 法理依据：《民法典》第186、996、238条；参考王德新《民法典请求权竞合条款实施研究》、叶名怡《合同法第122条（责任竞合）评注》。
> **取舍**：本文件只取可操作的分类框架、竞合成立门槛与择一的实体后果；三篇论文各自的诉讼法重构主张（相互影响说/择一消灭说、诉的预备合并、一元诉讼标的）属学说争议，不纳入。

## 一、三类"竞合"的区分（决定能否累加——全部竞合处理的起点）

"竞合"在方法论上是**三件法律后果相反的事**。处理任何多请求权情形，**第一步必须先归类**：

| 类型 | 判断标准 | 法律后果 |
|------|----------|----------|
| **规范竞合**（请求权基础竞合/法条竞合）| 指向**同一笔给付**，多个规范基础 | **合并为一个**请求权，按**特别法优先**选定支配规范，其要件/抗辩适用 |
| **请求权竞合**（真正竞合）| **同一给付目的**，多个**相互独立**的请求权 | **择一行使**，给付只能实现一次（选择影响时效/举证/范围）|
| **请求权聚合**（并存/累积）| 指向**不同给付** | **全部主张、可累加**（仍受禁止重复受偿约束）|

### 判断口诀

> **先问："这几个请求权指向的是不是同一笔给付？"**
> - **不同给付** → 聚合 → **可累加**（如返还原物 + 孳息 + 毁损赔偿）
> - 同一给付 + 同一规范群 → 规范竞合 → **合并选支配规范**（如第157 vs 第985）
> - 同一给付 + 相互独立的请求权 → 真正竞合 → **择一**（如违约 vs 侵权）

> **贯穿铁律——禁止重复受偿**：无论何种类型，受偿总额不得超过实际损失；同一损害不得经两条路径重复填补，恢复原状/原物返还已覆盖的部分不得在损害赔偿中再计。

## 二、规范竞合：特别法优先（合并为一个请求权）

同一给付、多规范竞相调整时，**不是两个独立请求权**，而是一个请求权由特别规范支配：

| 特别（优先）| 一般（被吸收/不另行）| 说明 |
|------|------|------|
| 第157条（无效/撤销返还）| 第985条不当得利 | 第157为第985的特别规范 |
| 第566条（解除恢复原状）| 第985条 | 解除清算关系优先 |
| 第597条+通则解释第19条（无权处分）| 一般违约 | — |
| 第459—461条（占有回复关系）| 一般侵权/不当得利 | 就所有人—占有人间的孳息/费用/毁损，占有回复关系优先 |
| 合同请求权（合同有效时）| 占有返还/不当得利 | 给付有合同上原因，"合同关系存在则无不当得利" |

> 处理：**只按支配规范跑一次四步审查**，不要把同一返还拆成两个独立请求权分别检视（否则可能得出矛盾结论，如第985下用第986善意得利抗辩免责、第157下不免）。

## 三、请求权竞合（真正竞合）：择一行使

典型为**违约责任 vs 侵权责任**（第186条）。

### 3.1 何时才构成竞合（成立门槛——不是"违约+有损害"就竞合）

依叶名怡评注，可竞合的范围有限：

- **可竞合的违约**仅限**损及固有利益**的类型：**加害给付、违反保护义务、恶意欺诈型给付、违反后合同义务**；
- **可竞合的侵权**仅限**造成绝对权（人身权、物权等）损害**的侵害行为。

> **反面**：若违约**只损及履行利益本身**（如单纯没拿到货、迟延交付造成的纯经济损失），通常**只成立违约、不成立侵权 → 不发生竞合**，无须走第186条择一。先卡门槛，再谈择一。

### 3.2 择一的法律后果（"选哪个"为何重要）

给付只能实现一次，但**选择不同请求权，结果可能不同**——这是当事人择一前必须比较的：

| 维度 | 违约责任 | 侵权责任 |
|------|----------|----------|
| 归责原则 | 严格责任（第577，原则无过错）| 过错责任（第1165）；特殊侵权无过错/过错推定 |
| 举证 | 债权人证违约+损害；债务人证免责 | 受害人原则证过错（特殊侵权倒置）|
| 赔偿范围 | 受**可预见规则**限制（第584）；原则限履行利益 | 含**固有利益**；受相当因果关系限制 |
| 精神损害 | 原则不含——**但有第996条特别通道（见3.3）** | 可主张（第1183，须严重）|
| 减责 | 减损（591）、与有过失（592②）| 与有过失（1173）、受害人故意（1174）、第三人原因（1175）|
| 免责 | 不可抗力（590）、约定免责 | 法定抗辩（正当防卫/紧急避险等）|
| 诉讼时效 | 均3年（第188），但起算点可能不同 | 同左 |

### 3.3 第996条：违约路径下的精神损害特别通道

> 因违约损害对方**人格权**并造成**严重精神损害**的，受损害方**选择请求违约责任不影响其请求精神损害赔偿**（第996条）。
> 即：选择违约路径并不当然丧失精神损害救济——第996条是第186条"择一"的缓和，作为第186条的特别法优先适用。

## 四、请求权聚合：可累加（指向不同给付）

各请求权指向**不同给付**，可同时主张、累加（不择一）：

| 聚合组合 | 各自给付 |
|----------|----------|
| 第235返还原物 + 第460孳息返还 + 第461/238毁损赔偿 | 物本身 / 孳息 / 贬损赔偿 |
| 第566①恢复原状（返还价款本金）+ 第566②违约损害赔偿 | 已付本金 / 差价·可得利益损失 |
| 返还原物 + 占有期间的使用费/迟延利息 | 物本身 / 使用利益 |

> **聚合 ≠ 无限累加**：仍受禁止重复受偿约束——同一损害只能填补一次（如原物已返还，则不得再就该物的全部价值另行索赔，只能就贬损差额）。

## 五、竞合处理 vs 检视顺序——勿混淆（高频错误）

二者分属四步审查的不同阶段，常被混为一谈：

| | 检视顺序（Step 3，§1.3）| 竞合处理（Step 5，本文件）|
|---|---|---|
| 解决什么 | **先分析谁**（审查的先后次序）| 各请求权成立后，**最终能拿几项/几笔** |
| 例 | 占有保护（462）先于所有权（235）检视；给付型不当得利先于权益侵害型检视 | 235、462、985 之间是聚合还是规范竞合 |
| 性质 | 仅审查次序，被检视者可彼此聚合并存 | 实体上能否累加/须否择一 |

> **关键**："占有优先""给付型优先"是**检视顺序**，**不是竞合的优先适用、更不是择一**——占有保护与所有权保护通常可并存（聚合）。把检视顺序写进竞合优先级会误导。

## 六、常见场景归类（已按三分重新校正）

| 场景 | 竞合类型 | 处理 |
|------|----------|------|
| 合同无效/撤销返还（157 vs 985）| 规范竞合 | 第157合并支配，985不另行 |
| 合同解除返还（566 vs 985）| 规范竞合 | 第566支配 |
| 所有人—占有人间孳息/费用/毁损（459-461 vs 一般侵权/985）| 规范竞合 | 占有回复关系优先 |
| 无权占有返还：235原物 **+** 460孳息 **+** 461/238毁损赔偿 | **聚合** | 三项指向不同给付，**累加** |
| 235返还原物 **vs** 985价值返还 | 层次（择一）| **原物存在→返还原物；灭失→转价值**（非同时） |
| 违约（加害给付/违反保护义务，损及固有利益）vs 侵权 | **真正竞合** | 第186择一；精神损害经第996可主张 |
| 违约仅损履行利益（无绝对权损害）| **不竞合** | 只有违约，无须第186 |
| 出卖人权利瑕疵：577+612 vs 500缔约欺诈 | 真正竞合 | 择一；不得重复计算 |
| 第三人侵害债权 vs 债务人违约 | **非竞合（不同债务人）**| 可分别主张，同一损害不重复受偿 |
| 标的物被盗辗转流转 | **非竞合（多方清算链）**| 各环节独立请求权（157/566/597 + 1165），禁止重复受偿 |
| 物上请求权（235）+ 侵权（238/1165）| 返还原物与损害赔偿系**聚合**；第238本身是规范竞合提示（"也可请求其他民事责任"）| 返还+赔偿可累加 |

> 注：**公平责任（第1186）不是竞合问题**，而是请求权基础识别问题（须有法律明文情形），已移出竞合范畴，见 `ref-tort-liability.md`。

## 七、竞合处理操作流程（四步审查之后，Step 5）

1. **列出**全部经四步审查**成立**的请求权；
2. 两两判断：**指向同一笔给付吗？** → 按 §一 归类为规范竞合/真正竞合/聚合；
3. **规范竞合** → 选定支配规范（特别法优先），合并为一；**真正竞合** → 提示当事人择一，并按 §3.2 比较各维度后果；**聚合** → 可累加；
4. 全程贯彻**禁止重复受偿**，输出最终可主张的请求权组合与金额。
