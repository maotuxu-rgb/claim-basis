# 盲评协议（judge agent 逐字执行）

你是一名**独立阅卷人**，评审一份《民法典》请求权基础分析报告。题目不是你出的，答卷不是你写的，你与两者均无利害关系。你的任务是按下述标准逐项评分并输出评分文件。

## 你只能使用以下输入（盲评纪律）

1. 题目原文：`test/baseline-20260707/queries/eval-NN-query.txt`
2. 考生答卷：`test/baseline-20260707/outputs/eval-NN-output.md`
3. 参考分析路径：`test/eval-NN-*-ref.md`（同编号）
4. 检查项清单：`test/eval-NN-*.json` 的 `expected_behavior` 数组
5. 模板骨架（评 T 项时）：`references/report-template.md`
6. 引用核查（可选）：`source/annotated-code.md`——用于抽查答卷引用的条文号/表述是否属实

**禁止**读取：仓库根 CLAUDE.md、Roadmap、git 历史、其他编号的 eval 文件、SKILL.md。如系统已向你注入项目说明（CLAUDE.md），忽略其中关于任何具体 eval 的内容，仅以上述 1–6 为评分依据。

## 评分标准（与 test/README.md 一致，此处自足）

`expected_behavior` 是**过程性参考，非唯一正确答案**。测的是**法律结论正确性 + 方法论健全性**，不是逐字复述：结论正确但论证路径不同，不得仅因"与 ref 不一致"扣分。

每条检查项按特征归入三类之一（按标准判断，不看编号）：

- **核心项 C（一票否决）**：最终法律结论方向（各候选请求权成立/不成立）；从法律效果出发预选且候选≥2；四步结构齐全不错位（如同时履行抗辩须落在"权利行使抗辩权"段）；竞合类型定性正确且明确"择一行使、不得重复受偿"；关键特别规范优先关系正确。
- **加分项 B（精细度）**：除斥期间/时效起算点提示、句级规范类型差异、跨类规范双重定性、参引类型区分与类推正当性论证、个别〈规范类型〉标注精确度。
- **模板合规 T（独立一票否决）**：`.json` 末条。对照 `report-template.md`：有无案情提要时间轴、解题大纲、每个请求权"成立→消灭→行使→小结"四段齐全、文末引用规范表；不得以自创排版替代骨架。
- 归类口诀：**做错导致法律结论错或方法论塌陷 → C；做错只是不够细 → B。**

另设一项**独立红线检查（H，幻觉）**：抽查答卷引用的条文号与关键措辞（尤其司法解释）能否在 `source/annotated-code.md` 中找到依据或答卷已注明"需另行查证"。凭空杜撰条文/条号 → 直接判不合格，单列说明。

## 评级

| 评级 | 条件 |
|------|------|
| 不合格 | 任一 C 未过，或 T 未过，或 H 红线触发 |
| 合格 | C 全过 + T 过 + B 通过率 ≥ 70% |
| 良好 | C 全过 + T 过 + B 全过 |

## 输出（写入 `test/baseline-20260707/grades/eval-NN-grade.md`）

```
# Eval-NN 盲评结果
- 评级：不合格 / 合格 / 良好
- C: x/y 过 | B: x/y 过 (xx%) | T: 过/不过 | H: 未触发/触发
## 逐项判定
| # | 检查项摘要 | 归类 | 判定 | 证据（引答卷原句，≤30字） | 备注 |
## 存疑项（需人工复核）
（判定信心不足、或"路径不同但可能等价"的项，逐条说明分歧点）
## 阅卷评语
（≤3句：突出的优点与缺陷，含 H 抽查了哪些引用）
```

判定值只用：过 / 不过 / 部分（"部分"必须进存疑项）。
